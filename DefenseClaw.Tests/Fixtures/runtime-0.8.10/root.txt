Usage: defenseclaw [OPTIONS] COMMAND [ARGS]...

  Enterprise governance layer for AI coding agents.

  Discovers AI usage, scans skills, MCP servers, plugins, and code before they
  run, and provides audit, telemetry, and enforcement.

  Multi-connector:
    One gateway enforces N agent-native connectors (codex, claudecode,
    hermes, antigravity, omnigent, and others) tracked under guardrail.connectors. Add one
    with 'defenseclaw setup <connector>' (choose Add when prompted),
    remove with 'defenseclaw setup remove <name>'. Scope policy per peer
    with 'defenseclaw guardrail ... --connector X', and inspect the
    roster with 'defenseclaw status' / 'defenseclaw guardrail status'.
    Note: OpenClaw/ZeptoClaw use the proxy path and cannot be multi peers.

Options:
  --version       Show the version and exit.
  --version-json  Emit the exact build version as JSON and exit.
  --help          Show this message and exit.

Commands:
  agent          Inspect locally installed agent surfaces.
  aibom          AI Bill of Materials — scan the active connector(s)'...
  alerts         View and manage security alerts.
  audit          Audit trail helpers (activity logging).
  codeguard      CodeGuard native skill/rule asset management.
  config         Inspect and validate DefenseClaw configuration.
  doctor         Verify credentials, endpoints, and connectivity.
  guardrail      Control guardrail policy: status, enable/disable,...
  init           Initialize DefenseClaw environment.
  keys           Inspect and manage DefenseClaw API keys.
  mcp            Manage MCP servers — scan, block, allow, list, set, unset.
  migrations     Inspect and recover the migration cursor.
  observability  Inspect canonical observability collection and routing...
  plugin         Manage DefenseClaw plugins — install, list, remove,...
  policy         Manage DefenseClaw security policies — create, list,...
  quickstart     Zero-prompt end-to-end setup with safe defaults.
  registry       Manage external skill / MCP catalog sources.
  reset          Wipe user state so 'defenseclaw quickstart' starts clean.
  sandbox        [experimental] Manage openshell-sandbox standalone mode.
  settings       Operator settings (parity with the TUI setup panel save...
  setup          Configure DefenseClaw components.
  skill          Manage agent skills — search, install, scan, block,...
  status         Show DefenseClaw status.
  tool           Manage tool-level block/allow lists.
  tui            Launch the DefenseClaw interactive Textual dashboard.
  uninstall      Uninstall DefenseClaw (reversibly by default).
  upgrade        Upgrade DefenseClaw to the latest version.
  version        Show DefenseClaw CLI / gateway / plugin versions and...
